# Agent CLI Workflow (milestone)

Milestone m-8 targets making the `backlog` command the single default instruction entry point for both humans and agents. Scope includes short generated setup text, local workflow guides (the `backlog instructions` family), clearer command help, and optional MCP support.

## Summary

- Single entry point: `backlog` CLI doubles as the instruction surface, reducing reliance on external docs for both human and agent onboarding.
- Short generated setup text: repo-specific quick-start output generated by the CLI itself.
- Local workflow guides: per-command guidance material (the `backlog instructions <topic>` family) shipped with the tool.
- Clearer command help: `--help` surfaces treated as part of the workflow, not just reference.
- Optional MCP support: MCP server as an opt-in companion surface alongside the CLI.
- The milestone file itself is minimal (id + title + one-paragraph description); task-level detail lives in the linked BACK tasks and in guides such as `backlog instructions overview`.
