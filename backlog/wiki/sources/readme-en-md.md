# README.en.md Summary

English landing page for Backlog.md, a Markdown-native task manager & kanban visualizer for any Git repository.

## Key Points

- Plain `.md` task files, 100% offline/private, cross-platform
- AI-ready via CLI instructions (recommended) or MCP connectors
- Modern Web UI bound to loopback (`127.0.0.1`) by default with `--host` opt-in for LAN
- Supports `BROWSER` env variable for custom browser launch
- Stable `--json` output for read commands (`task list/view/search`, `doc list`)
- Gantt chart with planned-vs-actual dual-layer comparison
- LLM-managed Wiki knowledge base
- autoCommit scopes to exactly the files each write touches
