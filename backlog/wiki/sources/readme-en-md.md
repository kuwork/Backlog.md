# README.en.md 英文产品概述

Backlog.md 的英文落地页，一款 Markdown 原生的任务管理与看板可视化工具，适用于任意 Git 仓库。

## 要点

- 纯 `.md` 任务文件，100% 离线/私有，跨平台
- 通过 CLI 指令（推荐）或 MCP 连接器实现 AI 就绪
- 现代 Web UI 默认仅绑定回环地址（`127.0.0.1`），`--host` 可选开放 LAN
- 支持 `BROWSER` 环境变量指定浏览器启动
- 读取命令（`task list/view/search`、`doc list`）提供稳定的 `--json` 输出
- 甘特图支持计划 vs 实际双层对比
- LLM 维护的 Wiki 知识库
- autoCommit 仅精确暂存每次写入触碰的文件
