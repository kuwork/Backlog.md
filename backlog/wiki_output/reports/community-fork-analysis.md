#### 1. 任务过滤与规范化

```typescript
const ganttTasks: GanttTask[] = useMemo(() => {
  return tasks
    .map((task) => {
      const start = task.plannedStart ? toDate(task.plannedStart) : null;
      const end = task.plannedEnd ? toDate(task.plannedEnd) : null;
      if (!start && !end) return null;  // 跳过没有日期的任务
      const normalizedStart = start ?? end;
      const normalizedEnd = end ?? start;
      // ...
    })

```

**优雅处理：** 没有 `plannedStart`/`plannedEnd` 的任务被静默排除。空状态消息解释如何添加日期。

#### 2. 日期解析

```typescript
function toDate(value: string): Date | null {
  if (!value) return null;
  const hasTime = value.includes(" ") || value.includes("T");
  const iso = value.replace(" ", "T") + (hasTime ? ":00Z" : "T00:00:00Z");
  const d = new Date(iso);
  return Number.isNaN(d.getTime()) ? null : d;
}
```

支持 `YYYY-MM-DD` 和 `YYYY-MM-DD HH:mm` 两种格式。内部规范化为 UTC ISO 字符串。

#### 3. 缩放级别与视口

```typescript
type ZoomLevel = "1d" | "7d" | "30d" | "90d" | "365d" | "all";
```

| 缩放 | 行为 |
|------|-----------|
| `all` | 显示从最早任务开始到最后任务结束的完整范围 |
| `1d` / `7d` / `30d` / `90d` / `365d` | 锚定到「今天」，从当前日期向后/向前显示窗口 |

**视口计算：**
```typescript
const now = Date.now();
const start = now - dayMs; // 今天前一天
const min = start;
const max = min + windowMs;
```

#### 4. 智能时间轴刻度

| 缩放 | 刻度步长 | 对齐方式 |
|------|-----------|-----------|
| `1d`, `7d` | 每日 | 午夜 |
| `30d` | 每周 | 周一对齐 |
| `90d`, `365d`, `all` | 每月 | 每月 1 日 |


#### 5. 条形定位（核心渲染逻辑）

**无 SVG，无 canvas — 纯 CSS：**

```tsx
<div className="flex-1 relative h-6">
  {/* 背景网格线 */}
  <div className="absolute inset-y-2 left-0 right-0 border-t border-dashed" />
  
  {/* 条形 */}
  <div
    className={`absolute top-0 bottom-0 rounded-full ${color} shadow-sm`}
    style={{

```

**定位数学：**
```typescript
const startOffset = ((clampedStart - range.min) / range.span) * 100;
const width = Math.max(((clampedEnd - clampedStart) / range.span) * 100, 2);
// 最小 2% 宽度，因此短任务保持可见
```

**裁剪：** 超出视口的任务被裁剪：
```typescript
const clampedStart = Math.max(startMs, range.min);
const clampedEnd = Math.min(endMs, range.max);
if (clampedEnd <= range.min || clampedStart >= range.max) return null;
```

### 3.9 技术亮点

| 决策 | 理由 |
|----------|-----------|
| **无图表库** | 保持包体积小巧；Tailwind CSS 处理所有样式；更易于维护 |
| **百分比定位** | 无需 ResizeObserver 即可响应；随容器宽度自然重排 |
| **Task 类型中的日期字符串（非 Date 对象）** | 与现有的 `createdDate` / `updatedDate` 模式一致；易于 markdown 往返 |
| **内部 UTC 规范化** | 避免时区错误；显示使用 `toLocaleDateString()` 进行用户本地格式化 |
| **内联日期更新** | 即时反馈；websocket 自动跨客户端同步 |
| **2% 最小条形宽度** | 防止在宽缩放级别下单日任务消失 |
| **周一对齐的每周刻度** | 遵循 ISO 周约定；项目规划者熟悉 |
