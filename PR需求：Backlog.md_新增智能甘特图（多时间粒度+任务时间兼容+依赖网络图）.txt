# PR需求：Backlog.md 新增智能甘特图（多时间粒度 + 任务时间兼容 + 依赖网络图）

## 一、PR 基本信息

- PR 名称：feat: 新增 Backlog 甘特时间线视图（Gantt View）
- 迭代类型：功能新增
- 优先级：高
- 适用系统：Backlog.md Web UI（`backlog browser`）
- 需求目标：在现有 Web 界面新增甘特图页面，基于已有 `plannedStart` / `plannedEnd` / `createdDate` / `updatedDate` / `dependencies` 字段进行纯 React/CSS 渲染，补齐时间维度可视化能力

## 二、需求背景

当前 Backlog.md 任务模型已沉淀大量真实业务数据，包含：

- 必填字段：任务 ID（`id`）、任务名称（`title`）、创建时间（`createdDate`）
- 可选字段：计划开始时间（`plannedStart`）、计划结束时间（`plannedEnd`）、更新时间（`updatedDate`）、任务依赖关系（`dependencies`）

现有系统无时间线可视化能力，存在以下问题：

1. 存量任务大多**无计划时间**，仅有创建 / 更新时间，无法直观查看任务周期
2. 少量规划任务有明确计划起止时间，无法可视化排期
3. 任务依赖关系纯文本记录，无图形化链路，难以识别关键路径
4. 缺乏全局时间视图，无法按日 / 周 / 月 / 季度 / 年度快速切换观察项目节奏

因此需要新增一套**完全兼容存量字段、自动适配时间、动态渲染**的智能甘特图模块。

## 三、需求目标

1. 新增 `/gantt` 路由页面，左侧任务列表 + 右侧时间轴的标准布局
2. 制定**自动化时间取值规则**，兼容仅有 `createdDate` 的无计划时间任务
3. 支持 **5 档时间粒度切换**：日 / 周 / 月 / 季度 / 年度
4. 解决「单日期任务在大跨度视图被压缩成细线」的展示问题
5. 支持基于 `dependencies` 的任务依赖可视化箭头
6. 无计划起止时间的任务自动兜底最小宽度，保证界面可交互

## 四、功能详细需求

### 4.1 整体页面布局

页面分为左右固定结构：

1. **左侧：四列固定表格**
   - 任务 ID
   - 任务名称
   - 开始时间（解析后的有效开始时间，见 4.2）
   - 结束时间（解析后的有效结束时间，见 4.2
   - ）
   - **表头排序**：四列均支持点击排序，仅改变前端显示顺序，不影响任务实际数据。排序交互与「所有任务」页面保持一致：双箭头图标（`↑`/`↓`），未激活灰色、激活高亮，三种状态外框等宽避免表头抖动。

2. **右侧：动态甘特图时间轴区域**
   - 顶部时间粒度切换器（日 / 周 / 月 / 季度 / 年）
   - 动态刻度时间轴
   - 任务时间条渲染（基于解析后的起止时间）
   - 任务依赖箭头叠加层（SVG 或 CSS）

### 4.2 核心：任务起止时间解析规则（强制优先级）

为统一所有存量、新增任务渲染逻辑，固定以下优先级：

#### 开始时间取值规则
1. 存在 `plannedStart` → 优先使用计划开始时间
2. 无计划开始时间 → 使用 `createdDate` 的日期部分（`YYYY-MM-DD`）

#### 结束时间取值规则
1. 存在 `plannedEnd` → 优先使用计划结束时间
2. 无计划结束时间、存在 `updatedDate` → 使用 `updatedDate` 的日期部分（`YYYY-MM-DD`）
3. 仅有 `createdDate`（无计划时间且无更新时间）→ 启用**动态最小宽度兜底**（见 4.3）

### 4.3 最小宽度兜底机制（解决单点任务压缩问题）

禁止任务在任意视图下渲染为 0 宽度，采用「**视图粒度匹配动态时长兜底**」策略：

- 日视图：兜底最小时长 = 4 小时（视觉宽度，便于同一天多任务垂直错开）
- 周视图：兜底最小时长 = 1 天
- 月视图：兜底最小时长 = 1 天
- 季度 / 年度视图：兜底**固定视觉像素宽度**（保证可见色块，如 8px）

兜底逻辑：
仅当任务**只有创建时间**（无 `plannedStart/End`、无 `updatedDate`）时自动填充，不影响有完整计划时间或更新时间的正常任务。

> 注：日视图的「4 小时」为纯前端视觉策略。因日期字段均为 Date-only，前端在日视图下将单天任务渲染为从当日起始偏移一段距离、持续约 4 小时视觉宽度，使同一天的多条任务能够垂直错开排布而不完全重叠。

### 4.4 同一天多任务渲染规则

1. 真实时间完全重叠 / 同天任务：**垂直微错开排布**（垂直方向偏移 4–8px），不遮挡、可独立点击
2. 不做水平挤压，保证精细视图下可区分多条任务
3. 大跨度视图下自动聚合视觉层级，保持界面整洁

### 4.5 时间粒度切换功能

支持 5 档一键切换：

- 日视图：适合查看近几日密集开发任务排布
- 周视图：适合迭代进度查看
- 月视图：适合月度项目复盘
- 季度视图：适合中长期项目概览
- 年度视图：适合全年项目大盘总览

切换特性：
- 切换粒度时**自动重算任务位置与最小宽度**
- 时间轴刻度、步长、缩放比例自动适配
- 大跨度视图自动开启 hover 详情提示

### 4.6 任务依赖可视化（简易网络图）

1. 读取 Task 的 `dependencies` 字段（前置任务 ID 列表）
2. 在甘特图层上方叠加箭头连线（SVG 绝对定位覆盖层）
3. 连线规则：**前置任务结束位置 → 后置任务开始位置**
4. 多条依赖自动错位防缠绕（贝塞尔曲线或折线）
5. 依赖箭头跟随时间粒度缩放自适应

### 4.7 交互细节

1. 任务条 hover：展示完整信息（ID、名称、起止时间、是否兜底渲染）
2. 大跨度视图单点任务 hover：展示真实计划时间（如有）
3. 支持点击任务条打开任务详情弹窗（复用现有 `TaskDetailsModal`）
4. 时间轴支持**拖拽平移**（左右滑动查看更多时间）
5. 支持点击某任务高亮其依赖链路（前置/后置任务高亮，其他任务变淡）
6. 左侧表格排序状态变更后，右侧甘特条同步按新顺序重新排布

## 五、输入输出与数据依赖

### 输入数据（完全复用现有字段，无需新增）

- `id` — 任务 ID
- `title` — 任务名称
- `plannedStart` — 计划开始时间（可选，Date-only）
- `plannedEnd` — 计划结束时间（可选，Date-only）

- `createdDate` — 创建时间（必选，`YYYY-MM-DD HH:MM`）
- `dependencies` — 前置任务 ID 列表（可选，`string[]`）
- `status` — 任务状态
- `priority` — 优先级
- `milestone` — 归属里程碑

### 输出效果

- 结构化任务时间列表
- 自适应甘特时间条
- 可视化任务依赖网络
- 全粒度兼容的项目时间视图

## 六、边界场景覆盖（关键验收点）

1. 有 `plannedStart` + `plannedEnd` → 正常展示计划工期
2. 只有 `createdDate` + `updatedDate` → `createdDate` 作开始、`updatedDate` 作结束
3. 只有 `createdDate` → 自动兜底最小宽度
4. 单日多条任务 → 自动错开不重叠
5. 年度视图单点任务 → 保留可见色块，不消失
6. 存在多级任务依赖 → 完整渲染链路
7. 任务点击 → 正确唤起 `TaskDetailsModal`
8. 暗黑模式 → 时间条、连线、hover 提示均正确适配

## 七、非本次迭代范围

1. 不新增数据库/字段
2. 不支持手动拖拽改时间（后续迭代）
3. 不做复杂关键路径计算（后续迭代）
4. 不引入外部甘特图库（保持纯 React/CSS 渲染）
