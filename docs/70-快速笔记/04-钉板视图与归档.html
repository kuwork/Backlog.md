钉板视图与归档

钉板视图与归档

除了信息流和日历，/memos 还提供第三种视图——钉板：所有 memo 以钉在黑板上的黄色便利贴呈现，适合一眼浏览全部笔记的分布与堆积。

进入钉板

在 /memos 页面切换视图到钉板（URL 参数 ?view=board 可深链直达）。钉板模式下快速捕获编辑器和标签过滤行自动隐藏，黑板区域固定填满容器、不随页面滚动；右上角按钮可将黑板全屏（全屏的是黑板本身，弹窗与按钮都在其内部，依然可见）。若浏览器不支持 WebGL，黑板位置会显示提示文案而不是空白页。

便签的呈现规则

每张便签的位置与外观是确定的：由 memo ID 哈希派生纸张变体、图钉颜色、倾斜角度和落点，刷新页面永远不会重洗布局。每张便签采用固定高度（约 150px），内容超出时在末尾以省略号截断，长 memo 不会无限撑高钉板、也不会遮挡邻居便签；看板边缘的便签会自然层叠，被压住的笔记仍然可以 hover 或点击发现。

便签交互

  • 悬停：便签抬起并浮到最上层，右上角浮现归档按钮
  • 点击：在便签上按下并原地抬起，打开笔记弹窗——弹窗内容与信息流卡片的编辑体验一致（正文、标签、保存、删除），标题即笔记首行文字
  • 归档：点击悬停时出现的归档图标，或关闭弹窗后在卡片菜单选择 Archive——便签/卡片随即从板面和信息流消失

归档说明

归档把笔记文件从 backlog/memos/ 移动到 backlog/archive/memos/，笔记内容原封不动。归档是单向的：当前版本没有取消归档入口，也没有归档浏览视图；归档后的笔记不再出现在信息流、日历计数、标签过滤和钉板中。新建项目时 backlog init 会同时创建 memos 与 archive/memos 两个目录。
