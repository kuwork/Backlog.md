Web 备忘页面

Web 备忘页面

启动 Web 界面后，侧边栏的 Memos 入口（展开列表 + 折叠图标栏）打开 /memos 页面。页面在同一组件内提供信息流与日历两种模式，共享同一个选中日期，通过 ?view= 参数深链直达。

信息流模式

信息流是 /memos 的默认视图：顶部一个快速捕获编辑器，下方是按时间倒序排列的 memo 卡片流。

快速捕获

  • 顶部 composer 复用富文本粘贴同款编辑器：支持粘贴图片、拖入文件、Word 文档转换，粘贴的图片在保存前自动提升到 assets/paste/
  • 点击保存按钮或按 Cmd/Ctrl+Enter 保存，新 memo 立即置顶显示，无需刷新
  • 保存失败时笔记内容被保留并显示本地化错误横幅，不会静默丢失

卡片流

  • 卡片显示创建时间、正文渲染结果（Markdown、Mermaid 图表、wiki 链接与实体 ID 自动链接）与只读标签 chips。正文中的实体 ID 区间（如 back-101~105）与斜杠列表（如 back-101/102/103）会被渲染为单个触发器，点击展开 portal 下拉列出区间内每个 ID 的可点击链接
  • 标签栏采用单行折叠的历史标签条：近期使用过的标签压缩为一行、active 标签置顶，点击展开可过滤；卡片支持内联编辑、归档与删除（归档详见钉板视图与归档）。在 composer 中输入 #话题#（如 #login#）可标注该 memo 的主题而不污染正文，该闭合语法会被识别为话题标签
  • 无限滚动基于 IntersectionObserver 哨兵自动加载后续分页；memo 变更通过 WebSocket memos-updated 广播实时同步到所有打开的标签页

钉板模式

/memos 还有第三种视图——WebGL 便利贴钉板：?view=board 直达，便签落点确定、黑板固定不滚动、支持全屏，hover 便签可归档、点击打开编辑弹窗。详见钉板视图与归档。

日历模式

点击视图切换进入日历模式：CSS Grid 月视图按每日 memo 数量做强度渐变着色（数据来自 GET /api/memos/calendar），今天高亮，不依赖第三方日历库。

  • 翻月：prev / next / today 按钮跨年翻月并重新拉取计数；相邻月的首尾日在网格中淡化
  • 点选某天：在网格下方就地展开 DayPanel（不跳转页面），列出当日全部 memo，可内联编辑或删除
  • 补录历史日期：DayPanel 自带 composer，写入的 memo 以 createdDate 钉住所选日期（ID 前缀随之派生），适合会后补记
  • View in feed：面板动作将 selectedDate 设为日期过滤 chip 并切回信息流模式，即「点选某天即过滤 feed，清除 chip 即回到全部」
  • 深链：?view=calendar&date=YYYY-MM-DD 直达该月、预选该日并自动展开面板

与全局搜索联动

全局搜索对话框的「备忘」标签页检索 memo，结果行点击后跳转到 /memos?date=<day> 的当日视图（memo 没有独立详情路由）。详见全局搜索与搜索与知识互联。

界面语言

Memos 页面的全部文案（捕获提示、日历按钮、错误横幅等）已覆盖 en / zh-CN / zh-TW / ja 四个语言，跟随界面语言设置即时切换。
