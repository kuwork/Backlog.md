隐私说明

这个站点是托管在 GitHub Pages 上的纯静态页面。它没有后端，没有登录，没有表单，也没有分析脚本。

我们不收集什么

本站不收集姓名、邮箱、IP 地址或任何可用于识别个人的信息。站内没有注册、订阅或付款流程。

Cookie 与追踪

本站不设置 Cookie，不加载第三方追踪脚本，也不做任何跨站画像。语言切换完全靠页面之间的跳转完成。

第三方请求

页面字体来自公共 CDN（jsdelivr 与 unpkg）。请求字体时，你的 IP 地址会按 CDN 提供方自己的隐私政策被处理。除此之外，页面资源都由本站域名直接提供。

你的项目数据

Backlog.md 本身把任务、文档和决策保存在你自己项目目录里的 Markdown 文件中，不会上传到本站或任何云端服务。本站无法访问你的仓库内容。

问题反馈

对这份说明有疑问，请在 GitHub 仓库提交 issue： kuwork/Backlog.md/issues
